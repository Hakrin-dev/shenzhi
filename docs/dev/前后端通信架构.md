# 前后端通信架构

已锁定：**人对人走 Next.js（TS）微后端；人对模型走 Python + FastAPI。**

```text
浏览器 React
  ├─ /api/auth/*     → Next.js + Better Auth（登录注册鉴权）
  └─ /api/v1/*       → Next.js 转发（补 X-ShenZhi-User-Id，去掉 Cookie）
                         ↓
                    BUSINESS_BACKEND_URL
                         ↓
                    FastAPI（apps/backend）
                      会话 / 检索 / 模型 / SSE
```

- 浏览器禁止依赖内部后端 URL，禁止 `NEXT_PUBLIC_API_URL`。
- FastAPI 不读 Better Auth 的 `user/session` 表；只信任 Next 转发的身份头。
- 问 AI 契约见 `docs/dev/AI搜索-开发文档.md`：`POST /api/v1/search/sessions`、`GET /api/v1/search/messages/{id}/stream`。
