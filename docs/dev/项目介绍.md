# 深知 AI 助手 · 项目介绍

本文说明产品做什么、目前已实现哪些需求与功能。进度按日记更新见 [开发日志](./开发日志.md)，完整需求见 [PRD](../prd/PRD-AI搜索.md)，代码见 [GitHub](https://github.com/Hakrin-dev/shenzhi)。

## 产品是什么

深知 AI 助手是网站里的智能问答能力。用户从首页进入，可以像搜索引擎一样查文献，也可以切换到问 AI，在对话里选择大模型、选择回答风格、上传文档或开启联网搜索，系统逐字返回答案，并在需要时展示引用来源。

网站用 Next.js 做页面和接口，AI 能力目标形态在 Python FastAPI。用户只访问网站，不直接连 AI 服务。界面采用深知蓝为主色、智能体青绿为点缀，详见 [配色说明](./配色说明.md)。当前 dev 主分支与 feat ai agent B 实验分支并行，下文分别说明各自已落地的功能。

## dev 主分支已实现

**搜索与入口**

首页有统一搜索框，可在普通搜索与问 AI 之间切换，切换入口在加号菜单里。普通搜索会跳到搜索结果页，页面与交互已就绪，检索内容目前为本地假数据。问 AI 会跳到 agents ask 页面，可把首页输入的问题、所选模型与风格带过去。

**输入框与工具栏**

界面参考 alphaXiv。输入区下方只保留四个控件：加号、上传、模型选择 pill、圆形箭头发送。没有单独的搜索文字按钮，Enter 提交当前模式，Alt+Enter 可跳普通搜索。

加号菜单里可切换普通搜索与问 AI、回复风格、联网开关，以及插件与技能入口。上传按钮用于本地文件与知识库引用。回复风格有快速、深度、灵感、质疑四档，与模型选择无关。

**大模型选择**

模型 pill 点开可向下展开列表，展示各家模型名称与厂商标识，不是回复风格。当前目录见 apps web lib data chat models ts，接口字段 model 传模型 ID。

已配置 DeepSeek V3 与 DeepSeek R1，dev 上可直接选。GPT-4o、GPT-4o mini、Claude 3.5 Sonnet、Gemini 2.0 Flash、GLM-4 Plus 在列表中展示，需订阅后启用。下拉菜单优先向下展开，贴近屏幕底部时会自动向上翻转，避免被浏览器裁切。

后端 GET search config 与创建会话接口已接收 model 字段，FastAPI 仍返回占位文案，尚未按所选模型路由到各家 API。

**问 AI 与对话**

问 AI 页支持多轮输入、流式展示、停止生成。会话与流式协议已搭好，网站转发 FastAPI。会话未持久化，配额与历史列表未做。

**登录**

支持邮箱注册与登录、GitHub 登录，基于 Better Auth 与 PostgreSQL。

## feat ai agent B 实验分支已实现

B 分支在旧目录结构下把第一阶段核心需求跑通。

**问 AI 与模型**

已接入 DeepSeek 真流式，含 R1 思考链。支持多轮、停止与继续、四档风格、Markdown 与公式。模型侧为默认、订阅、自带密钥三档，与 dev 新的多模型列表不是同一套 UI，合并时需统一。

**附件与联网**

可上传 PDF、Markdown、文本、Word，可联网搜索，有来源卡片。

**登录与用户**

NextAuth 与 SQLite，与会话 CRUD、历史列表骨架已有，写库与历史回灌未完成。

## 尚未实现

dev 上真实大模型按 model 路由、文献检索、会话持久化、引用联动、收藏分享等仍待做。B 分支能力合入 dev 时保留 Better Auth。
