# 配色说明

深知前端颜色定义在 apps web styles globals css，组件通过 Tailwind 类名引用，不直接写色值。

## 品牌色

深知蓝 174A7E 用于 Logo 主按钮导航高亮和核心标题，传达专业与可信。

深色 123A63 用于按钮悬停和夜间侧栏底色。

浅底 E8F1F8 用于功能卡片背景引用证据区和选中态，日间侧栏与此同色。

页面背景 F6F9FC 全站铺底，比纯白更柔和。

正文 17212B 用于正文与重要数据。

智能体强调 0F766E 仅作点缀，约占界面一成，用于联网开关等状态，探索青 brand cyan 与此同色。主按钮与发送箭头用 primary 深知蓝。

辅助色灵犀紫与桂冠金保留，用于图谱与标签等少量场景。

## 使用约定

主操作一律用 primary，悬停用 primary dark。联网等智能体相关状态用 agent。引用区与侧栏浅块用 primary soft 或 panel。夜间模式由 html dark 自动切换令牌，组件无需改类名。

详细进度见 [开发日志](./开发日志.md)。
