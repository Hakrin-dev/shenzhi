# ShenZhi Backend 协作规则

本文件适用于 `apps/backend/`。同时遵循仓库根目录的 `AGENTS.md`。

## 后端约束

- FastAPI 承载系统核心业务 API、业务校验、数据处理、持久化及 AI / 科研能力编排。
- API 层负责路由、使用请求与响应 Schema 完成参数校验并调用 Service，不在路由函数中堆积复杂业务逻辑。
- 业务逻辑进入 `services/`；请求与响应模型进入 `schemas/`；持久化模型进入 `models/`；配置和基础设施能力进入 `core/`。
- 上述目录按实际职责使用，不为满足目录形式创建空层级或只做无意义转发的文件。
- 外部服务和科研能力通过现有 Service、Client 或 Adapter 边界接入，不让其协议细节扩散到业务 API。
- 接入外部能力时明确输入输出、超时、异常转换和不可用行为；Mock 或降级实现必须与真实实现清晰区分。
- 配置和密钥从现有配置体系及环境变量读取，不在代码中硬编码；新增必要配置时同步更新示例配置。
- Python 依赖统一使用 `pyproject.toml` 与 `uv.lock` 管理，通过 `uv` 执行环境同步和命令，不重新引入 `requirements.txt`。
- 修改完成后，使用 `uv run` 执行与改动范围相符的测试或检查。

如需改变 API 契约、数据模型或服务边界，先说明兼容性和受影响的调用方。
